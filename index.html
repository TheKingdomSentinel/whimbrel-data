Whimbrel Research: medtech signals data

Daily-updated, machine-readable US medtech buying signals. Stable event ids, parsed dollar amounts, and a public source link on every row.

  • index.json: machine-readable manifest of everything here
  • signals-latest.json: buying signals from the last 7 days
  • hot.json: companies with a buying-window event in the last 14 days
  • llms.txt: this site, for machine readers
  • methodology.md: how the data is collected, dated, and windowed, and what these files exclude

Query it by MCP

The same data is queryable over the Model Context Protocol (Streamable HTTP, no authentication):

https://whimbrel-signals-mcp.whimbrelresearch.workers.dev

Tools: latest_signals, whats_hot, signal_of_the_day, weekly_pulse, about_the_data.

Claude (web and apps): Settings → Connectors → Add custom connector → paste the URL above.

Claude Code:

claude mcp add --transport http whimbrel https://whimbrel-signals-mcp.whimbrelresearch.workers.dev

Cursor: Settings → MCP → Add new server, or add to ~/.cursor/mcp.json:

{"mcpServers": {"whimbrel-signals": {"url": "https://whimbrel-signals-mcp.whimbrelresearch.workers.dev"}}}

VS Code (Copilot): add to .vscode/mcp.json:

{"servers": {"whimbrel-signals": {"type": "http", "url": "https://whimbrel-signals-mcp.whimbrelresearch.workers.dev"}}}

Other MCP clients: any client that speaks Streamable HTTP can use the URL directly; no key is required.
